# AI Browser Android Project Rules

## Mandatory Guidelines

1. **No fake implementations.** Never stub, mock, or simulate functionality in production code.
2. **Read before modifying.** Always read the full file you intend to change before editing.
3. **One feature group at a time.** Implement and verify one feature group before starting the next.
4. **Build after changes.** Run a build after every change and fix all errors before moving on.
5. **Fix errors before moving on.** Do not proceed to the next feature until the current one compiles and passes.
6. **No unused code or comments.** Remove all commented-out code and unused imports.
7. **Follow existing patterns.** Match the style, naming, and architecture of the existing codebase.
8. **Secure by default.** Do not log secrets, expose APIs, or introduce security vulnerabilities.
9. **Test on device when possible.** Verify UI behavior on a real device or emulator.
10. **Keep it minimal.** Avoid unnecessary abstractions, frameworks, or dependencies.
